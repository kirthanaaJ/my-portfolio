My Projects

GyroGlove: An IoT - based Wearable for Tremor Management

GyroGlove is an IoT-based wearable glove designed to assist with hand tremor management. The system uses an ESP32 and MPU6050 IMU sensor to detect hand movement and a motor-driven flywheel mechanism to generate counter-torque against tremors. The project also aims to record tremor-related data for monitoring and visualization.

Campus Navigation System

Campus Navigation System is a web-based application developed to help students and visitors find locations within our college campus. It provides campus location information and calculates suitable routes between locations using Dijkstra's shortest path algorithm.
